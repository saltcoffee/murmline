# Changelog

## 0.1.0

### English

- Republished the plugin as **Murmline** with the plugin ID `murmline`.
- Capture thoughts of up to 140 characters from the ribbon or command palette. Combined emoji count as one character. Post as often as you like, including offline.
- Browse a private timeline grouped by local date. Load earlier thoughts in pages of 50 and delete an individual thought after reviewing its text.
- Keep each thought as a Markdown file in your vault. Posts remain readable after you disable Murmline.
- Use Murmline in English or Simplified Chinese on Obsidian 1.8.7 or later.

### 简体中文

- 插件更名为 **Murmline**，以新插件 ID `murmline` 重新发布。

- 从侧栏或命令面板记录想法，每条最多 140 字，组合表情计为一个字。支持离线发布，条数不限。
- 按本地日期回看私人时间线，每次最多加载 50 条更早的记录。核对正文后可单独删除一条想法。
- 每条想法独立保存为仓库内的 Markdown 文件，停用插件后仍可阅读。
- 支持 Obsidian 1.8.7 及以上版本，界面跟随宿主显示英文或简体中文。
